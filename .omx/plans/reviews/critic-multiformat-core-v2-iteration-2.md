# 评论员终审：Babel Core v2（第 2 轮）

日期：2026-08-17  
角色：Critic  
结论：`ITERATE`

## 阻塞意见

第 1 轮离线包边界修订仍有两个 P0 缺口：

1. Windows 只明确嵌入 WebView2 离线安装器，没有为全部 EXE/DLL、worker、OCR 和适配器建立 PE 静态导入、运行时加载集合与版本化系统 DLL/API-set 白名单，因此无法机器证明没有隐藏运行时依赖。
2. 双平台真实下载产物的离线安装/启动、Arch 执行位和 ABI 闭包尚未进入 Phase 0 不可豁免退出门，可能在核心、DAG 和 IPC 已投入后才发现发行边界不可行。

## 要求的最小修改

- Windows 建立“包内文件 + 嵌入式 WebView2 安装结果 + 版本化系统 DLL/API-set 白名单”依赖闭包，MSVC/UCRT 等非白名单运行时必须随应用提供或离线安装。
- 将双平台真实下载件的禁网安装、启动、内置组件加载探针、Arch 执行位与双平台 ABI 差集检查加入 Phase 0 退出条件。

## 已确认通过

数据安全、身份绑定、DAG fencing、IPC 认证、快照导出、性能测量、RALPLAN 决策和“预算不等于已实现”表述没有新增阻塞矛盾。
