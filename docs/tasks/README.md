# Babel Tower 任务系统

任务来自当前代码缺陷，不是练习题。执行者必须先读 [CURRENT_STATE.md](../CURRENT_STATE.md)、[05_STATE_OWNERSHIP.md](../05_STATE_OWNERSHIP.md) 和 [architecture/dangerous-changes.md](../architecture/dangerous-changes.md)，提交设计、实现、回归测试和证据。

## 优先级

- P0：数据安全、真实桌面验收、质量门禁和事实源冲突。
- P1：状态一致性、设置运行时行为、工作台回归。
- P2：反馈、关于页和发布体验打磨。

任务卡不会直接给出完整实现；它提供入口、约束、验证和验收标准。
