# 新开发者挑战

挑战不提供完整答案；必须提交问题理解、定位证据、设计、实现、测试和复盘。

1. **Challenge 1：UI**：修复一个空状态或可访问性问题。
2. **Challenge 2：State**：修复一个 store 派生状态 bug 并补测试。
3. **Challenge 3：Settings**：让一个已有设置真正驱动运行时。
4. **Challenge 4：IPC**：扩展一个小型 Bridge/Tauri 契约。
5. **Challenge 5：Feature**：完成一个跨 Core、IPC、UI 的小功能。
6. **Challenge 6：Consistency**：修复一个 revision、dirty 或项目隔离问题。
7. **Challenge 7：E2E**：为真实桌面流程写 filesystem/restart 断言。
8. **Challenge 8：Release**：独立收集 release-gates 全部证据。

挑战顺序对应 [tutorials](../tutorials/README.md) 和 [tasks](../tasks/README.md)。
