## Documentation Reliability Rule

Use current code and fresh commands first. `PROJECT_STATUS.md` is useful but appends newer increments without rewriting earlier summaries; `DESIGN.md` mixes target design and implementation status. Both require dated capability matrices rather than prose-only completion claims.
